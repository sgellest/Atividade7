# Atividade 7

## Descrição

Esta é uma atividade aplicada para treinamento da linguagem JavaScript, utilizando a lógica.

## Sobre o projeto

O primeiro script funciona como um conversor de moedas, possuindo a opção de conversão para euro e dólar, ambas com uma cotação já definida em constante. 
####
O segundo script serve como um sistema de acesso a um clube, onde verifica se a pessoa preenche os requisitos para entrar. Caso não preencha, não pode entrar no clube.
####
O terceiro script é um operador ternário para notas de escola, ao qual retorna se o aluno está aprovado se a sua nota for maior ou igual a 6. Caso seja menor que 6, informa que o aluno está reprovado.
